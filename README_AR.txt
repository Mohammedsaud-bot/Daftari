دفتر المذاكرة (Daftari) — المشروع المصدري الكامل
================================================
هذا هو نفس تطبيق daftari-preview.apk: الكود الأصلي (lib/) كما هو حرفياً،
وكل الصور والأصوات والخطوط والمحتوى (assets/)، والأيقونة وشاشة البداية،
واسم الحزمة com.daftari.daftari والإصدار 0.3.0 (5).

الحصول على APK بدون تثبيت أي برنامج (GitHub):
1) أنشئ مستودعاً جديداً في github.com وارفع كل محتويات هذا المجلد
   (بما فيها المجلد المخفي .github).
2) افتح Actions ثم Build APK ثم Run workflow.
3) بعد دقائق نزّل الملف من Artifacts: Daftari-APK (بداخله app-release.apk).
4) انقله للجوال وثبّته (فعّل التثبيت من مصادر غير معروفة).

على جهاز فيه Flutter:
  flutter create --org com.daftari --project-name daftari --platforms android .
  flutter pub get
  flutter build apk --release

ملاحظة: الأمر flutter create لا يستبدل الملفات الموجودة؛ يضيف فقط ملفات
Gradle الناقصة المناسبة لنسخة Flutter عندك.
الـ APK الناتج موقّع بمفتاح التطوير (debug)، مناسب للتثبيت المباشر،
ولو ثبّتت فوق النسخة القديمة واختلف التوقيع احذف القديمة أولاً.

ما الجديد في 0.3.0 — كتاب 12 كاملًا
------------------------------------
- الوحدات الخمس كلها مفتوحة: السفر، التعليم، المنزل، الطبيعة، والمراجعة.
- 14 جلسة جديدة (3 لكل وحدة + جلستا مراجعة) بجانب جلسة السفر الأصلية وجسر البداية.
- 167 كلمة في القاموس (كل كلمات قوائم الكتاب) مع المعنى والتعريف ومثال مترجم ونطق.
- القواعد: الجمل الشرطية، المضارع التام مع ever/already/just/yet، still/no longer/anymore،
  so/or، الاحتمال could/perhaps، الكلام المنقول، صفات -ing/-ed، used to/would، go + -ing،
  مقارنة الظروف (faster / more slowly / farther).
- زر «الجلسة التالية» في نهاية كل جلسة، وقائمة كل جلسات الوحدة في تبويب الدروس.
- الجمل الجديدة تُنطق بصوت الجهاز (الصوت المسجّل متوفر لجلسة السفر الأصلية فقط).
- لتعديل المحتوى: عدّل tool/words_data.py و tool/lessons_data.py ثم شغّل
  python tool/build_content.py
